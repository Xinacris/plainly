## 1. Core flows and data model

| Flow | What Amazon does | Entities |
|---|---|---|
| Home | A wall of carousels, deals and personalized rows | Product, Category |
| Search & filters | Query, category scope, sidebar filters, sort, sponsored results mixed in | Product, Facet (brand, price, rating, stock) |
| Product page | Gallery, buy box, variants, bullet points, long description, Q&A, reviews | Product, Review |
| Cart | Line items, quantities, save for later, subtotal | CartItem {productId, qty, price snapshot} |
| Checkout | Address, then delivery option, then payment, then place order | Address, Order |
| Orders & returns | Order history, tracking, return or replace flow | Order {id, items snapshot, total, placedAt, eta, status}, Return {orderId, itemId, reason, status} |
| Account | Sign-in, addresses, payment methods, Prime, lists | User, Address |

**Where the data lives:**
- **DummyJSON:** Product, Category and Review.
- **localStorage:** CartItem, Order, Return and Address.
- **Price snapshots:** orders keep a copy of prices at purchase time, so past orders don't change if the catalog does.
